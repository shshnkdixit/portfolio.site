--Personal Portfolio Website

A personal portfolio website built to showcase my profile, skills, projects, and journey as a developer.

This project was created as part of Major League Hacking (MLH) Global Hack Week — Open Source, exploring website development with the help of GitHub Copilot.

--Features

- Personal portfolio website
- Custom HTML structure and styling
- JavaScript-based interactivity
- Simple and accessible web experience
- Easy to customize and extend

--Tech Stack

- HTML5 — Website structure
- CSS3 — Styling and layout
- JavaScript — Interactive functionality
- GitHub Copilot — AI-assisted development

--Getting Started

Run Locally

1. Clone this repository:
   
   git clone https://github.com/shshnkdixit/portfolio.site.git

2. Open the project folder:
   
   cd portfolio.site

3. Open "index (1).html" in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.

The goal of this project is to build a personal online presence, practice front-end development, and explore AI-assisted coding while participating in an open-source community event.
